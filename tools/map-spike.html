The world map — camera spike (390 × 844)

Swipe down to pull back, swipe up to go in — the same rule the Hollow already uses, so the whole game is one vertical ladder: map, garden, Hollow. Tap the garden to dive in; tap a locked parcel to see it refuse. The camera is one CSS transform over one world box.

What this spike found: the dive cannot land on the real garden. That screen is its own composition — sky, quest strip, plots as tappable cards, the burrow door — and rebuilding it inside a world box would mean maintaining the garden twice. So the map is a layer above the existing garden, and the end of the dive is a cross-fade, not a zoom that keeps going. The garden below is a stand-in for where that hand-off happens.
